Monitor your services.

Asura checks services, records incidents and sends alerts. It runs as a single Go binary with SQLite storage and includes a web interface, an API and public status pages.

Configure and integrate

The configuration reference covers server, storage, authentication and monitoring settings. The API reference describes endpoints and the permissions needed to use them. Read the architecture guide for an overview of the application.

The web interface is rendered by Go and enhanced with HTMX and Alpine.js. Static assets are included in the binary; no separate frontend server is required.

Asura is available under the MIT license. Source code and releases are on GitHub.
